# RE² Signal Lineage — Scoring Input Trace
**BL-C1 | Brain 2 | April 12, 2026**

Maps every scoring input in `location-iq.ts` and `six-index.ts` back to its raw API source.
Generated by grepping all `r.<field>` / `report.<field>` access patterns and cross-referencing
the fetch module for each source.

---

## Scoring Engines Overview

Two engines run independently and produce different score types:

| Engine | File | Output | Use Case |
|--------|------|--------|----------|
| Location IQ | `location-iq.ts` | 0–100 `locationIQ` score | Primary RE² composite |
| Six-Index | `six-index.ts` | 6 sub-index scores (0–100 each) → composite | Dashboard index view |

Both consume the same `LocationIntelReport` produced by `fetchLocationIntel()` in `index.ts`.

---

## Location IQ — Signal Lineage

### Architecture
```
Location IQ = (W_n × NIQ) + (W_s × SIQ) + (W_t × TIQ) + (W_l × LIQ)
```
Weights are concept-specific (see `CONCEPT_WEIGHTS` in `location-iq.ts`).
